Cards Wrap Gap

Flex container

The parent gets display: flex. The children line up in a row by themselves.

Wrapping

flex-wrap: wrap lets the row break onto a second line instead of squeezing.

Gap

gap is the space between items. No margins on the last child to clean up.

Basis

flex: 1 1 200px means: grow, shrink, start from 200px wide.
